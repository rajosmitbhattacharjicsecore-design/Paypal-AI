# 3-minute demo

1. Show the dashboard and point out fictional demo data.
2. Create a draft invoice.
3. Ask the Copilot which invoices are overdue.
4. Show cash-flow assumptions; clarify this is not a bank balance.
5. Record an approval decision; no payout is executed.
6. Review operational alerts and the activity log.
7. Explain that PayPal is currently demo mode.
