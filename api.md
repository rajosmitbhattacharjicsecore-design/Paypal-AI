# API overview

Prototype routes: `GET /api/health`, `GET /api/dashboard`, `GET/POST /api/invoices`, `POST /api/invoices/{id}/paypal` (demo only), `POST /api/agent/chat` (offline planner), `GET /api/approvals`, `POST /api/approvals/{id}/decision` (decision record only), `GET /api/forecast`, `GET /api/risks`, and `GET /api/audit`. Interactive docs: `/docs`.
